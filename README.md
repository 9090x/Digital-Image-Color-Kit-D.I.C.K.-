## 🤔 Что это вообще такое?

**D.I.C.K.** (Digital Image Color Kit) — это высокопроизводительный инструмент для обработки изображений, который умеет всё, что может "пережевать" легендарная библиотека `stb_image.h`. 

Если объяснять максимально просто: ты скармливаешь ему обычную фотографию, а он выдает из неё:
- 🌈 **Цветовые градиенты** (плавные переходы цветов, извлеченные из изображения).
- 🎨 **Цветовые палитры** (вытягивает основные доминирующие цвета, чтобы ты мог использовать их в своём дизайне).
- 💻 **ASCII-арт** (превращает фото в стильную текстовую картинку из символов, как в старых фильмах про хакеров).

Почему это работает быстро? Потому что вся тяжелая математика и обработка пикселей написаны на **C++**. А чтобы тебе не пришлось страдать с компиляторами, всё это аккуратно упаковано в **Python** с помощью магии `pybind11` и `scikit-build-core`. Ты получаешь скорость C++ с удобством Python.

---

## ⚡ Почему это круто?

- 🚀 **Максимальная скорость**: Основная обработка изображений работает на C++. Никаких зависаний, только чистая производительность.
- 🐍 **Бесшовная интеграция**: Проект собирается через `scikit-build-core`. C++-код превращается в обычный Python-модуль, который можно импортировать одной строчкой.
- 🖥️ **GUI из коробки**: Есть готовый графический интерфейс. Не нужно лезть в консоль, если не хочешь. Всё интуитивно понятно и красиво оформлено.
- 🛠️ **Универсальность**: Работает с любыми форматами, которые поддерживает `stb_image.h` (PNG, JPEG, BMP, TGA и другие).

## 📦 Установка (для тех, кто просто хочет, чтобы работало)

Если ты не хочешь разбираться со сборкой компиляторов, просто склонируй репозиторий и запусти готовый скрипт:

```bash
git clone https://github.com/9090x/Digital-Image-Color-Kit-D.I.C.K.-.git
cd Digital-Image-Color-Kit-D.I.C.K.-
```

**Для Windows:**
Просто дважды кликни на `RUN.bat` или запусти `RUN.ps1` в PowerShell. Скрипт сам подготовит окружение и запустит графический интерфейс.
